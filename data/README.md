# Benchmark data

| file | what | license |
|---|---|---|
| `heysquad_dev_vosk.jsonl.gz` | Streaming-ASR traces of the HeySQuAD human-recorded dev questions | CC BY 4.0 (derived from HeySQuAD) |
| `heysquad_dev_vosk.stats.json` | Build statistics (kept / dropped rows) | CC BY 4.0 |
| `squad_v2_passages.jsonl.gz` | Every unique SQuAD v2.0 paragraph (train + dev), the retrieval corpus | CC BY-SA 4.0 (SQuAD) |

Both are regenerated by [`scripts/build_heysquad_traces.py`](../scripts/build_heysquad_traces.py).

## How the traces were made

1. **Audio**: the human-recorded split of HeySQuAD (validation, 4,158
   questions read aloud by people, 16 kHz). HeySQuAD pairs each spoken
   question with its SQuAD v2.0 paragraph.
2. **Streaming ASR**: each recording is fed to [Vosk](https://alphacephei.com/vosk/)
   (`vosk-model-en-us-0.22-lgraph`, Kaldi) in **100 ms chunks**, exactly as a
   live voice agent would. Every change of the running hypothesis is recorded
   with its audio timestamp. These are real interim results, so earlier words
   get **revised** ("what didn't like" → "what did microsoft"), not just
   extended.
3. **Timing**: word-level start/end times come from the final result.
   `speech_start_ms` / `speech_end_ms` are the first word's start and the last
   word's end.
4. **Cleaning**: HeySQuAD contains rows whose audio belongs to a *different*
   question (row 0 of the validation split reads a question about a Chopin
   sonnet against a question about integer factorisation). Rows where the ASR
   output and the reference question have a word-sequence similarity
   (`difflib` ratio) below **0.5** are dropped; see `heysquad_dev_vosk.stats.json`
   for counts.
5. **Corpus**: the 19,831 unique paragraphs of SQuAD v2.0 train + dev, so each
   question is answered from ~20k candidates, not just its own article.

## Record format

One JSON object per line:

```json
{
  "id": "5a2c41c8bfd06b001a5aeaaa",
  "question": "What did Microsoft announce that it would rename OneDrive for Business to?",
  "gold_doc_ids": ["sq-1bfcf49612d0"],
  "is_impossible": true,
  "asr_final": "what did microsoft announced that it would rename one drive for business to",
  "alignment": 0.8,
  "speech_start_ms": 1020,
  "speech_end_ms": 5610,
  "audio_ms": 6269,
  "events": [[1900, "what"], [2100, "what did my"], [2400, "what didn't like her"], [2600, "what did"], "..."],
  "words": [["what", 1020, 1200], ["did", 1200, 1350], "..."]
}
```

`is_impossible` is SQuAD v2.0's flag for questions the paragraph does not
answer. Those questions are still *about* their paragraph, so retrieval of the
paragraph is well defined and they are kept.

**Bring your own traces**: any JSONL with these fields works with
`forehear bench --traces my.jsonl.gz --corpus my_passages.jsonl.gz`. Logging
interim transcripts from a production agent and replaying them is the most
realistic benchmark you can run.
